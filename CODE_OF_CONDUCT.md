# Code of Conduct

Participate with respect. Harassment, discrimination, threats, doxxing, spam and bad-faith disruption are not welcome. Discuss code and evidence rather than people. Maintainers may moderate contributions and discussions to keep the project usable.

If a conduct issue arises, contact the maintainer privately through their GitHub profile rather than posting personal details in a public issue. No response-time promise or dedicated moderation address has been established yet.
