# Behaviour genome

Nine deterministic values (greed, fear, patience, risk tolerance, herd instinct, conviction, loss aversion, volatility affinity and drift) are derived from a founder seed in `[0, 1]`; children blend and may mutate them. Five of these match the current website specimen JSON exactly for the same ASCII seed. The remaining values match its market-trait preview calculations.

`personality()` returns two local labels based on fear, greed and conviction. This is not an AI model. A future voice adapter can interpret the fixed genome, but wording would then depend on its model, prompt and version and **would not** inherit the core's byte-for-byte determinism. No model SDK, API key or trade execution is included.
